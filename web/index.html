Dual-Skill Standards
การแยก Quantitative Analysis ออกจาก Super-Resolution:

เป็นไปตามกฎข้อ 1 ของ Coastal Skill: ตัวเลขการเปลี่ยนแปลงชายฝั่งคำนวณจาก Sentinel-2 Native 10m ส่วน 2.5m SR ใช้เฉพาะเพื่อการสังเกตการณ์เชิงสายตา (Visual Layer)

การควบคุม Contrast (Display Stretch):

ใช้ percentile limits 1% - 99% จาก Native ชุดเดียวกันในการแสดงผลทั้งสองฝั่ง เพื่อความเที่ยงตรงโดยไม่มี contrast bias

การควบคุมและคำนวณปัจจัยน้ำขึ้นน้ำลง (Tide & Season Matching):

• Overpass Time Matching: ใช้ภาพ Sentinel-2 วงโคจรสัมพันธ์กับดวงอาทิตย์ (Sun-synchronous) ที่บินผ่าน อ.ท่าศาลา เวลาเดิมสม่ำเสมอ (~10:35 น. ท้องถิ่น)
• Calendar Week Matching: คัดเลือกเฉพาะสัปดาห์แรกของเดือนเมษายน (5-6 เม.ย.) ข้ามปี 2566, 2567, 2569 เพื่อขจัด seasonal phenology และ monsoonal wind setup
• Decoupled Indicators: แยกตัวชี้วัด Waterline (ระบุสถานะ Apparent Seaward Movement พร้อมงบประมาณความคลาดเคลื่อน ±11.18 ม.) ออกจาก Mangrove Edge Advance Proxy (+635.45 ม.) ซึ่งเป็นแนวต้นไม้จริงที่ไม่ขึ้นกับระดับน้ำขึ้นน้ำลงรายชั่วโมง
• No Guesswork Slope: ปฏิบัติตามมาตรฐาน Phase 4 ของ Skill โดยไม่ใช้สูตรสมมุติตัวเลขความลาดชัน (Slope) กับหาดเลนงอกเพื่อป้องกัน pseudo-correction error
